# Бесплатное размещение «Королевств»

Проверено по официальным условиям 3 октября 2026 года. Новая постоянная ссылка ещё не создана: для публикации нужен принадлежащий владельцу игры аккаунт.

## Выбранный вариант: Render Free

Это полный Node.js-сервер, а не только хранение HTML. Игрок открывает постоянный адрес `*.onrender.com`; компьютер разработчика может быть выключен.

- Бесплатный экземпляр: 512 МБ RAM и 0,1 CPU.
- 750 бесплатных часов работы в месяц на рабочую область.
- После 15 минут без входящего трафика сервис засыпает. При следующем заходе запуск занимает примерно минуту. Во время активной игры наши клиенты регулярно получают состояние сервера.
- Render может перезапустить бесплатный сервис. В текущей версии комнаты находятся в памяти, поэтому перезапуск завершает партии. Постоянный URL не означает постоянное сохранение мира.
- Действуют лимиты трафика и сборки. Без добавленного способа оплаты превышение соответствующего лимита приводит к приостановке сервисов или сборок. При добавленной карте возможны дополнительные начисления: для этого бесплатного прототипа карта не нужна.

В `render.yaml` явно выбран `plan: free`. В настройках аккаунта выбирайте бесплатную рабочую область Hobby, а для Web Service — экземпляр Free. Наличие бесплатной рабочей области само по себе не делает выбранный вычислительный экземпляр бесплатным.

Официальные источники:

- https://render.com/docs/free
- https://render.com/docs/blueprint-spec
- https://render.com/docs/your-first-deploy

## Публикация после регистрации

1. Владелец сам создаёт аккаунт GitHub и подтверждает почту. Пароли не передаются в чат.
2. Создаётся репозиторий игры. В его корень загружаются `dist/`, `package.json`, `server.mjs`, `rooms.mjs`, `render.yaml` и документация. Логи, PID-файлы, временные URL и файлы туннеля загружать не нужно.
3. Владелец входит в Render через GitHub. Подключение доступа к репозиторию подтверждается в его браузере.
4. Render → New → Web Service → репозиторий игры. Выбирается **Free**. Build Command: `npm install --omit=dev`. Start Command: `npm start`. Health Check: `/health`.
5. После успешной сборки проверяются сайт, создание комнаты, подключение второго игрока, старт, боты и переподключение. Только после этого URL считается рабочим.

Можно использовать Blueprint с приложенным `render.yaml`, если он находится в корне репозитория.

| Koyeb Free | Node-сервис, 512 МБ, 0,1 vCPU | Засыпает после часа без трафика. Регистрация требует проверки карты; официальная FAQ описывает удержание $29 и возможную оплату выбранного плана. Не выбран как самый простой вариант без расходов. |

## Ресурсы

В `load-report.json` находится локальный замер реальных HTTP-запросов: одна комната, четыре человека, два снимка в секунду каждому, 20 секунд, строительство в процессе. Браузерную 3D-графику и туннель замер не включает. На другом процессоре и хостинге результаты будут отличаться; короткий замер не является гарантией долгой работы или максимального числа игроков.

Запуск замера:

```powershell
node tests/load-benchmark.mjs
```

Графика считается на компьютерах игроков. На игровом сервере Three.js не запускается. Linux на старый компьютер устанавливать не требуется: приложение работает под Windows с Node.js.
