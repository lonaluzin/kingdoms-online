# Королевства Online

Самостоятельный сайт: 3D-карта на Three.js и игровой сервер на Node.js. Работает вне ChatGPT. Сетевые комнаты: до четырёх правителей, включая ботов.

## Играть с друзьями

1. Откройте [игру на Render](https://kingdoms-online.onrender.com/). После простоя бесплатного сервера первый запуск может занять около минуты.
2. Укажите имя и количество ботов, затем **Создать сетевую игру**.
3. Нажмите **Скопировать приглашение**. Друзья открывают его, вводят имя и нажимают **Войти**.
4. После входа всех участников создатель нажимает **Начать партию**. Свободные места займут выбранные боты.

Для игры без друзей — **Одиночная игра с ботами**. Для переподключения обновите страницу в том же браузере и на том же адресе. Кнопка выхода из комнаты удаляет вашу привязку к ней; войти в начатую партию заново после выхода нельзя.

## Возможности

- Собственные столицы, ресурсы, здания, найм и исследования для каждого правителя.
- Общая карта и видимые армии всех держав. Походы, возвращения, захваты, потеря столицы и победа.
- Дипломатия между людьми с принятием или отклонением предложения. Договоры и объявления войны действуют для обеих держав.
- Боты строят, нанимают войска, торгуют и выбирают цели для походов. Боты оплачивают действия по тем же правилам. Первые две минуты они не атакуют державы других правителей.
- Военная, экономическая и политическая победа, засуха, варвары, древний зверь.
- Гостевой вход без регистрации. Сервер проверяет команды и не принимает от браузера ресурсные балансы, результаты битв или принадлежность земель.

## Запуск

Нужен Node.js 22 или новее. Дополнительных зависимостей нет.

```powershell
npm start
```

Откройте http://localhost:4174. Для другого порта задайте `PORT`. Node.js работает и в Windows; Linux для локального запуска не требуется.

```powershell
npm test
```

Проверки включают базовые правила игры, два независимых HTTP-клиента, отдельные экономики, общую карту, договоры, реальную передачу помощи, ботов, захват столицы, повторные и неверные команды.

## Сеть и ограничения прототипа

Сервер считает мир 10 раз в секунду. Клиенты получают снимки через HTTP каждые 500 мс; браузер не двигает экономику самостоятельно. Этот небольшой прототип использует HTTP polling и не требует WebSocket-библиотеки. Персональные ресурсы противника не передаются в снимках.

Партии находятся в памяти. Перезапуск сервера завершает их. Пауза и ускорение отключены; вкладку можно скрыть, а сервер продолжит партию. Комнаты без активных клиентов удаляются через час. Нет постоянных аккаунтов, рейтинга, сохранений между перезапусками, чата и механики привязки гостя к аккаунту.

## Внешний адрес

Игра опубликована на https://kingdoms-online.onrender.com/. Компьютер владельца для работы облачного сервера не нужен. Исходники: https://github.com/lonaluzin/kingdoms-online. Прежние ссылки Serveo больше не используются.

## Постоянное размещение

Подробная инструкция и сравнение бесплатных вариантов — в `HOSTING.md`. В `render.yaml` явно задан бесплатный тариф `plan: free`. Сервер опубликован 3 октября 2026 года: проверены загрузка 3D-клиента, два независимых игрока, боты, отдельные экономики и принятие дипломатического предложения.

Проект готов для Render или другого Node-хостинга. Для Render загрузите эту папку в собственный Git-репозиторий, подключите его в **New → Web Service**, выберите Node, `npm install --omit=dev` для сборки и `npm start` для запуска. Проверка здоровья — `/health`. Также приложен `render.yaml`. Сайт и API должны работать на одном домене. Требуется один экземпляр сервера: при масштабировании понадобятся общее хранилище комнат и маршрутизация игроков.

Официальная инструкция: https://render.com/docs/deploy-node-express-app

Лицензия Three.js находится в `dist/vendor/LICENSE`. Графика мира создаётся кодом, внешние игровые ассеты не загружаются.
